## 📌 Project Overview

This repository contains the practical work and learning activities completed during **Week 02 of the Networkwalks Cybersecurity Program**.

During this week, I explored different techniques used in the early stages of a cybersecurity assessment. The practical exercises focused on gathering publicly available information, performing domain and DNS analysis, identifying web technologies, conducting OSINT research, and discovering devices on a local network.

All activities were completed strictly for **educational purposes** and within the authorized scope of the training exercises and my personal local network.

## 🎯 Learning Goals

The main objectives of this week's practical work were to:

- Learn the basic concepts of footprinting and reconnaissance.
- Gather publicly available information about domains and DNS records.
- Identify technologies used by websites and analyze HTTP headers.
- Understand the purpose of Google search operators and GHDB.
- Explore OSINT investigation and link analysis with Maltego.
- Collect domain and email-related information using theHarvester.
- Scan and identify active devices on a local network.
- Prepare and document findings in a professional security report.

## 🔎 Main Practical Activities

### 1. Domain Footprinting and Reconnaissance

Different Kali Linux tools were used to collect information about a domain. This included checking public domain details, DNS records, website technologies, HTTP response headers, and possible web application firewall protection.

### 2. Google Hacking Database (GHDB)

Google search operators and GHDB techniques were studied to understand how search engines can reveal publicly indexed information. The activity focused on responsible use of search techniques and did not involve unauthorized access to private systems or sensitive information.

### 3. OSINT Investigation Using Maltego

Maltego was used to understand how information from public sources can be visually connected. The exercises explored entities, transforms, and relationship mapping to gain a better understanding of OSINT investigations.

### 4. Information Collection with theHarvester

TheHarvester was used for domain-based information gathering. Different public sources were explored to understand how information about domains and related data can support the reconnaissance phase of a security assessment.

### 5. Network Discovery with Zenmap

Zenmap was used to examine a local network and identify available devices. The practical work included viewing active hosts, IP addresses, MAC addresses, and network topology information.
